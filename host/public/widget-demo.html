Una página cualquiera de un "portal"

Esta página no usa el shell de NovaBank, ni React propio, ni Module Federation. Solo carga dos archivos .js y declara <div> con atributos data-*. Cada widget se monta solo y se configura con esos atributos. ← Volver al portal

1. Widget de crédito (configuración por defecto, en COP)

2. Otra instancia del mismo widget, configurada distinto (USD)

Mismo archivo .js, otra configuración: moneda USD, monto inicial 5.000, tasa 12 %.

3. Widget de seguros (preconfigurado: auto, plan Plus)

4. Montaje manual desde JavaScript

Además del auto-montaje, hay una API: NovaBank.credit.mount(elemento, props).

Cómo se usa en cualquier página

<div data-nb-widget="credit" data-tea="18" data-moneda="COP"></div>
<script src="widgets/credit-widget.js"></script>

En una plataforma con plantillas (como Liquid en Modyo) los valores de los data-* podrían ser generados por la plantilla en el servidor. Aquí están escritos a mano; la idea es la misma: la página decide, el widget obedece.
